# 🚀 Edu.tech

Edu.tech is a platform that connects students with the right tutors in a simple and efficient way.

## 🎯 Problem
Finding the right tutor is still difficult for many students, while many skilled tutors lack visibility.

## 💡 Solution
Edu.tech aims to bridge this gap by creating a direct connection between students and tutors.

## 🛠️ Tech Stack
- HTML
- CSS
  
## 📌 Features (Current)
- Landing page UI
- Responsive design
- Clean and modern interface

## 🔜 Upcoming Features
- Interactive UI with JavaScript
- Tutor-student matching system
- Backend integration
